# AI Resume Screening System

An AI-powered web application that automates resume screening and candidate-job matching for recruitment. The system extracts skills from uploaded resumes, compares them with job requirements, and recommends the most suitable candidates, helping recruiters reduce manual effort and improve hiring efficiency.

---

## 🚀 Features

### 👨‍💼 HR Module
- HR Registration & Login
- Post and Manage Job Openings
- View Candidate Applications
- AI-Based Resume Screening
- Candidate Ranking Based on Skill Match
- Manage Recruitment Process

### 👩‍🎓 Candidate Module
- Candidate Registration & Login
- Upload Resume (PDF)
- Automatic Resume Parsing
- AI Skill Extraction
- View Recommended Jobs
- Track Application History

### 🤖 AI Features
- Resume Parsing
- Skill Extraction
- Resume-Job Semantic Matching
- Candidate Ranking
- Intelligent Job Recommendation

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/AI-Resume-Screening-System.git

Navigate to the Project
cd AI-Resume-Screening-System
Install Dependencies
pip install -r requirements.txt
Run the Application
python app.py

Open your browser and visit: http://127.0.0.1:5000/

📌 Working
HR creates an account and posts job openings.
Candidates register and upload resumes.
The system extracts skills automatically from PDF resumes.
AI compares candidate skills with job descriptions.
Candidates receive relevant job recommendations.
HR views ranked candidates based on matching score.
Recruiters shortlist the best candidates efficiently.
